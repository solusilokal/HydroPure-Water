# 💧 HydroPure Water - Mini Website Depot Air Minum Isi Ulang

Mini website modern untuk **HydroPure Water** — penyedia layanan isi ulang air galon higienis & segar berbasis Reverse Osmosis (RO) dan sterilisasi Ultra Violet (UV). Dilengkapi sistem pemesanan langsung terintegrasi dengan WhatsApp.

---

## ✨ Fitur Utama
- **Hero & Profil Depot**: Tampilan visual modern dengan logo dan foto interior depot.
- **Kategori & Harga**: Pilihan produk dan layanan dengan simbol representatif (RO, Bio Energi, Galon Baru, Tukar Tambah).
- **Galeri Depot (Carousel)**: Galeri foto fasilitas, kebersihan, dan mesin pengolahan dengan *horizontal scroll* mulus.
- **Lokasi Depot**: Peta dan informasi alamat lengkap yang terhubung ke Google Maps.
- **Tanya Jawab (FAQ)**: Accordion interaktif untuk informasi jam operasional, minimal pesan, dan metode pembayaran.
- **Formulir Pemesanan WhatsApp**: Input nama, alamat, jenis pesanan, dan jumlah galon yang langsung otomatis menghasilkan pesan WhatsApp ke nomor depot.
- **Bagikan / Share Modal**: Modal interaktif untuk menyalin tautan dan membagikan profil depot ke WhatsApp, Facebook, dan X.

## 🚀 Cara Menjalankan Proyek Secara Lokal

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/solusilokal/HydroPure-Water.git
   cd HydroPure-Water
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000`.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```
   Hasil build akan tersimpan di direktori `dist/`.
